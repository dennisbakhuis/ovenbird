# ovenbird-sim

Development tooling: heat pump model fitting from recorded captures, open-loop runs of the
controller against captures, and simulation. Depends on `ovenbird-core` and the capture package.

To turn a recording into an ovenbird `history.db` for the Replay tab, see
`ovenbird_harness.convert` (harness package; `make convert-capture`, `dev/README.md`).
